Package Solution Picker

A browser-based decision-support tool that scores and ranks every possible cutting plan across an entire package — turning hours of manual evaluation into seconds.

Context

A single package (kapan) can hold up to ~1,900 rough stones. Every stone has many possible cutting solutions, and each one trades off yield, dollar value, clarity mix, and size distribution differently. Planners evaluated this by hand, stone by stone — a slow, inconsistent process.

The problem

There was no way to make decisions at the package level quickly or consistently. And the “best” answer isn't fixed — it depends entirely on what you're optimizing for, which shifts by customer and by market conditions. A tool had to make that priority explicit and adjustable.

What I built

A browser-based tool that scores 27,000+ cutting-plan combinations per package and ranks the best solution for every stone. Key design decisions:

  • Independent scoring weights — separate yield and value sliders, so users dial in exactly how much to chase weight versus dollars.
  • 23 configurable hard filters — clarity ranges, min yield/value, max loss, pointer clarity, colour, shape, and cut/charni priorities exclude solutions that don't qualify.
  • Default vs Optimised view — a side-by-side panel showing exactly what the user's filters changed.
  • Manual override with undo — the expert always keeps the final, reversible call.

Solutions are scored with a weighted model across yield, normalized value, and clarity/cut/charni priorities; any solution failing a hard filter is excluded, with a clearly-marked fallback when nothing passes.

Outcome

Planning time dropped by roughly 95% for the largest packages, and the tool earned Global CEO approval for customer deployment after executive review and demonstration.

What I learned

The winning principle was: optimize aggressively, but never take the decision away from the expert. Surfacing why a solution scored well — and making every choice reversible — was what turned an optimization engine into a tool planners actually trusted.
